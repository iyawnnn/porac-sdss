# DESIGN.md (retired)

This file is retired history. The v3 spec that lived here (navy sidebar, Porac Yellow,
`[data-shell="admin"]` override) was never shipped and no longer matches the product.

**`docs/design-system.md` is the single source for the visual system** (brand, tokens, typography,
logo, layout, components, accessibility).

The old urgency ramp and Hazard Urgency (amber / orange / red bands) were retired in manuscript
revision Phase 1. Operational Priority (`priority_index`) is a numeric queue order and is never
shown as Low / Medium / High bands.
